# Security Policy

Reporting process and GPG key: see the
[organization security policy](https://github.com/garlic-signage/.github/blob/main/SECURITY.md).

## Supported Versions

Only the latest release receives security fixes. Please update to it.

## Security Advisories

Fixed vulnerabilities are published as
[GitHub Security Advisories](https://github.com/garlic-signage/garlic-player/security/advisories),
with a CVE identifier where one is assigned. Ordinary bugs are tracked in the issues and the
changelog.

## Before Reporting

Please read the [Threat Model](docs/threat-model.md). It documents which
properties the garlic-player is designed to protect, which behaviours are
deliberate design decisions and which weaknesses are known and accepted for now.
Reports describing documented behaviour as a vulnerability will be closed with a
reference to that document.

Reports must include a proof of concept demonstrating the claimed impact.
Please agree on a severity assessment before requesting a CVE identifier or
contacting a CVE Numbering Authority.
